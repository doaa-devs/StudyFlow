# 📚 STUDYFLOW

### A Student Study Planner & Productivity Platform

STUDYFLOW is a personal software engineering project designed to help university students organize their academic tasks, plan study sessions, and track their learning progress.

## 🎯 Project Goals

- Organize academic tasks and deadlines.
- Plan study sessions efficiently.
- Manage subjects and study schedules.
- Track academic progress through analytics.
- Explore reminder features to support better study habits.

## ✨ Planned Features

- Task management
- Study planner
- Subject organization
- Reminders
- Progress analytics
- Clean and responsive user interface
